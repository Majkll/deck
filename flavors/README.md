# Flavors

This repository supports two special-agent flavors built on top of a common daily-driver baseline.

## Flavor 1: sysadmin / hacker / designer

Profile:
- systems administration
- hardware and software design
- experimentation and developer workflows
- security-minded tooling and operator support

Required skills:
- bash
- git
- networking
- grill-me-with-plans
- user questions
- debian
- NYM
- python3
- using-uv
- caveman
- OWASP

## Flavor 2: scientific / research / writing

Profile:
- scholarly writing
- LaTeX and PDF generation
- literature review and synthesis
- paper drafting and notes management

Required skills:
- bash
- git
- networking
- grill-me-with-plans
- user questions
- debian
- NYM
- python3
- using-uv

## Common baseline

Both flavors share the same daily-driver butler persona and the same security-first runtime.
