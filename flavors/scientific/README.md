# Scientific flavor

This flavor is optimized for literature work, writing, LaTeX, research synthesis, and PDF workflows on a secure Raspberry Pi setup.

## Core traits

- paper drafting and note synthesis
- research pipeline support
- scholarly writing and normalization
- reproducible local artifact management
- structured memory and literature tracking

## Required skills

- bash
- git
- networking
- grill-me-with-plans
- user questions
- debian
- NYM
- python3
- using-uv

## Default assumptions

- the user spends more time on writing and synthesis than direct systems maintenance
- local memory and notes are curated and version-controlled
- the runtime remains privacy-aware and reviewable
- the generated work is kept outside secrets-bearing contexts
